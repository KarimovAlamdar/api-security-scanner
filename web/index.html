5 "Killer" Features StackHawk & Snyk Lack

Engineered to solve the fundamental pain points of security teams: eliminating developer fatigue, detecting undocumented APIs, and enforcing zero-leakage enterprise governance.

Feature #1 • Highest Engineering Value

Zero-Click AI PR Auto-Fix (Automated Bot)

Developers hate reading PDF and HTML vulnerability reports. When our scanner detects a vulnerability, it connects the runtime fault to the exact Java file and line number, creates a security/auto-fix-... branch, applies a verified remediation patch, and opens a ready-to-merge Pull Request with test reproducers.

Feature #2 • Spec Drift

Shadow & Zombie API Discovery

Compares Java Spring/JAX-RS controller route mappings with your OpenAPI spec. Instantly catches hidden internal routes forgotten in code (SHADOW_API_EXPOSED) and deprecated endpoints lingering in API gateways (ZOMBIE_API_ENDPOINT).

🔒
Feature #3 • SOC2 & GDPR

100% Air-Gapped & Zero Data Egress

Unlike competitors who send your code or OpenAPI schemas to third-party clouds, --air-gapped runs completely offline on self-hosted runners. Generates cryptographic SHA-256 audit attestations with zero telemetry transmission.

🔄
Feature #4 • Real Exploiter

Stateful BOLA / IDOR Verification

Simulates authentic attacks: User A creates a dynamic object via POST, extracts the returned ID, and User B immediately tries to read/delete it. Zero false positives; confirms horizontal privilege escalation.

Feature #5 • OWASP GenAI Top 10

LLM & AI Agent API Gateways

Specialized security scanner for /chat, /completions, and agent endpoints. Fuzzes for prompt injection escapes, system prompt leaks, and guardrail bypass attempts.

How to Run Your First API Security Scan

Choose your setup method. Your license key is already configured below.

1
Add Secret in GitHub: Go to Settings > Secrets > Actions and add SCANNER_LICENSE_KEY with your key above.
2
Save Workflow File: Download or place in .github/workflows/security.yml in your repository.
3
Push & Auto-Fix: Every git push scans OpenAPI endpoints, blocks BOLA vulnerabilities, and opens Auto-PRs.
.github/workflows/security.yml 
name: API Security Scanner
on: [push, pull_request]

jobs:
  api-security:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Run API Security Engine
        uses: KarimovAlamdar/api-security-scanner@v1
        with:
          license-key: ${{ secrets.SCANNER_LICENSE_KEY }}
          spec-path: openapi.json
          auto-pr: true
